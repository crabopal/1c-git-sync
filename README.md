# 1C Git Sync

Windows-приложение на PowerShell: выгружает конфигурацию 1С в XML и отправляет её в Git.

## Скачать

Готовый архив программы лежит в [Releases](https://github.com/crabopal/1c-git-sync/releases/latest):

https://github.com/crabopal/1c-git-sync/releases/latest/download/1c-git-sync.zip

Git на клиентском компьютере не нужен: в архиве уже есть `PortableGit-64-bit.7z.exe`. Распакуйте ZIP и запустите `1C Git Sync.exe` или `run.bat`. При первом запуске портативный Git распакуется в `workdir`.

Кнопка **Обновить** внизу боковой колонки проверяет [Releases](https://github.com/crabopal/1c-git-sync/releases/latest), скачивает новый zip и перезапускает программу. Каталог `workdir` при этом не трогается.

Раздел **Packages** на GitHub для этого не используется: там публикуют npm, NuGet и Docker-образы. Архив приложения — это **Releases**.

## Запуск

1. Распакуйте архив из Releases (рядом со скриптом должен лежать `PortableGit-64-bit.7z.exe`).
2. Запустите `1C Git Sync.exe` или `run.bat`.

Нужна установленная платформа 1С (`1cv8.exe`).

## Действия

Слева три раздела, журнал открыт внизу окна:

- **Выгрузка** — состав и режим. «Выгрузить в Git» выгружает отмеченное и отправляет в Git. «Только Git» — индексация, commit и push. «Только push» — только уже созданные коммиты.
- **Загрузка** — что подставлять в базу. Кнопка «Загрузить в 1С».
- **Настройки** — база 1С, пользователь, репозиторий и ветка. «Начать с чистого клона» удаляет локальную копию и клонирует репозиторий заново.

Настройки (кроме пароля 1С) сохраняются в `workdir/config.json`. Каталог `workdir` в репозиторий не входит.
